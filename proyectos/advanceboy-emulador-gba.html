01El problema

Quería un emulador de GBA para Android con todo lo que espero como jugador (estados con miniatura, avance rápido, rebobinado, mandos físicos, sensores de cartucho) y, a la vez, un proyecto para salir de la web y trabajar con código nativo, gráficos y audio en tiempo real.

02La solución

La app está escrita en Kotlin y usa mGBA como núcleo, compilado con el NDK y CMake. Un puente JNI propio expone al lado Kotlin lo necesario: cargar ROMs, avanzar frames, audio, estados guardados y trucos.

El renderizado va por OpenGL ES con shaders seleccionables y un hilo de emulación cuyo ritmo marca el propio audio. GitHub Actions ejecuta tests del núcleo con ROMs de prueba, compila el APK en cada push y publica releases con tag.

03Arquitectura y flujo

  1. ROMBiblioteca con escaneo de carpetas: .gba, .gb, .gbc y .zip
  3. KotlinUI, controles, ajustes, mandos y sensores
  5. JNIPuente C ↔ Kotlin
  7. mGBA (C)CPU, vídeo, audio y hardware de cartucho
  9. OpenGL ES + audioFrames con shaders y sonido sincronizado

04Funcionalidades clave

Controles táctiles editables

Arrastra y redimensiona cada botón; posiciones independientes en vertical y horizontal.

Estados guardados

10 ranuras más autoguardado, con miniatura y fecha.

Velocidad y rebobinado

Desde cámara lenta 0,1× hasta avance 8× o sin límite, y rebobinado manteniendo pulsado.

Trucos

GameShark, Action Replay, CodeBreaker y Game Genie con detección automática del formato.

Hardware de cartucho

Reloj en tiempo real, vibración, inclinación, giroscopio y sensor solar mapeados a los sensores del móvil.

Shaders

Filtros nítido, pixelado, suave, scanlines, LCD y corrección de color GBA.

Mandos físicos

Bluetooth y USB con reasignación de botones.

Partidas accesibles

Partidas .sav importables y exportables, visibles desde la app Archivos mediante un proveedor de documentos propio.

06Retos técnicos

  1. Sincronizar vídeo y audio

    A velocidad normal, la escritura bloqueante de audio marca el ritmo (la GBA produce exactamente un segundo de audio por segundo emulado). En silencio, avance rápido o rebobinado, un temporizador a 59,73 Hz toma el relevo.

  2. Un único hilo para el núcleo

    Todo lo que toca el núcleo nativo debe ejecutarse en el hilo de emulación. El resto de hilos le envían trabajo mediante una cola concurrente.

  3. Almacenamiento en Android moderno

    Desde Android 11 los gestores de archivos no pueden entrar en Android/data. Las partidas se exponen con un DocumentsProvider propio.

  4. Releases reproducibles

    El workflow comprueba que el tag coincide con versionName y firma siempre con la misma clave para que cada APK se instale encima del anterior sin perder partidas.

07Resultados

  • Emulador de GBA, GB y GBC completo y usable a diario.
  • Pipeline de CI/CD: tests del núcleo, APK firmado y release automática por tag.
  • Experiencia real con código nativo, OpenGL y audio en tiempo real.

08Código

EmulatorThread.kt (extracto)
/**
 * Ejecuta el emulador: una iteración del bucle = un frame emulado.
 *  - Velocidad normal con sonido: la escritura bloqueante de audio marca el ritmo.
 *  - Silencio, avance rápido o rebobinado: temporizador a 59,73 Hz.
 * Todo lo que toca el núcleo nativo se ejecuta en este hilo; el resto usa post().
 */
class EmulatorThread(
    private val frameBuffer: FrameBuffer,
    private val audio: AudioOutput,
    private val callbacks: Callbacks,
) : Thread("Emulator") {

    @Volatile var fastForward = false
    @Volatile var rewinding = false
    private val tasks = ConcurrentLinkedQueue<Runnable>()

    fun post(task: Runnable) {
        tasks.add(task)
        wake()
    }

    override fun run() {
        Process.setThreadPriority(Process.THREAD_PRIORITY_URGENT_DISPLAY)
        var nextFrameTime = System.nanoTime()
        while (true) {
            runPendingTasks()
            if (quitRequested) break
            if (paused) { waitWhilePaused(); continue }

            nextFrameTime = when {
                rewinding -> stepRewind(nextFrameTime)
                fastForward -> stepFastForward(nextFrameTime)
                else -> stepNormal(nextFrameTime)
            }
            if (NativeBridge.pollRumble()) callbacks.onRumble()
        }
    }
}
