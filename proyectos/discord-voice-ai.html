01El problema

Quería poder hablar con un asistente de IA dentro de un canal de voz de Discord, como un participante más, sin tener que escribir un comando para cada pregunta.

02La solución

Bot en Python con discord.py y su extensión de recepción de voz. Un *sink* propio recibe el audio PCM de cada usuario, detecta voz y silencio calculando la energía (RMS) y, cuando alguien termina de hablar, envía el fragmento a Whisper para transcribirlo.

La transcripción va a un LLM que genera una respuesta breve y conversacional, que se sintetiza con TTS y se reproduce en el canal a través de FFmpeg.

04Funcionalidades clave

Escucha continua

Comandos !join y !leave; a partir de ahí el bot escucha sin más interacción.

Buffers por usuario

Cada persona tiene su propio buffer y estado, así que varias pueden hablar en el mismo canal.

Fin de frase

Umbral de energía y duración mínima para ignorar ruidos y fragmentos demasiado cortos.

No se escucha a sí mismo

Mientras reproduce una respuesta, el bot ignora el audio entrante.

Procesado asíncrono

Transcripción, respuesta y síntesis se ejecutan en segundo plano sin bloquear la recepción de audio.

Sin restos

Los WAV y MP3 intermedios se eliminan tras usarse.

06Retos técnicos

  1. Saber cuándo alguien ha terminado de hablar

    Sin VAD externo: cálculo manual del RMS de cada paquete PCM, umbral de silencio y duración mínima de audio para no transcribir ruido.

  2. Hilos y event loop

    El sink recibe audio en un hilo distinto al de asyncio; el procesado se programa con run_coroutine_threadsafe para no bloquear ninguno de los dos.

  3. Evitar bucles de eco

    El bot descarta el audio entrante mientras habla para no transcribir su propia respuesta.

07Resultados

  • Conversación por voz natural con un LLM dentro de Discord.
  • Varios usuarios en el mismo canal, cada uno con su propio buffer.
  • Base para experimentar con asistentes de voz en tiempo casi real.

08Código

main.py (extracto simplificado)
class ContinuousSink(voice_recv.AudioSink):
    SILENCE_THRESHOLD = 500   # amplitud RMS
    SILENCE_DURATION = 1.2    # segundos de silencio = fin de frase

    def wants_opus(self):
        return False          # queremos PCM

    def write(self, user, data):
        if user is None or self.voice_client.is_playing():
            return            # no escucharse a sí mismo

        pcm = data.pcm
        samples = struct.unpack(f"<{len(pcm) // 2}h", pcm)
        rms = math.sqrt(sum(s * s for s in samples) / len(samples)) if samples else 0
        now = time.time()

        rec = self.user_data.setdefault(user.id, {"buffer": bytearray(), "last": now, "busy": False})
        if rec["busy"]:
            return

        if rms > self.SILENCE_THRESHOLD:
            rec["buffer"].extend(pcm)
            rec["last"] = now
        elif rec["buffer"] and now - rec["last"] > self.SILENCE_DURATION:
            audio, rec["buffer"], rec["busy"] = bytes(rec["buffer"]), bytearray(), True
            asyncio.run_coroutine_threadsafe(self.process_audio(user, audio), self.bot.loop)

09Lo que aprendí
