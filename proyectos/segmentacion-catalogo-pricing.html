01El problema

Las tarifas de proveedor llegan en Excel con miles de referencias y formatos distintos.

Decidir qué productos dejan margen suficiente, a qué precio venderlos y cuáles priorizar se hacía revisando la hoja a mano, con fórmulas copiadas y criterios que cambiaban según quién lo hiciera.

02La solución

Desarrollé un script Python parametrizable que lee la tarifa del proveedor, normaliza columnas, cruza con el precio de venta y calcula el margen de cada SKU.

El resultado es un Excel segmentado por tramos de margen y coloreado con umbrales configurables, para que compras vea de un vistazo qué priorizar. La parte de limpieza de ficheros se expuso también como microservicio para usarla desde n8n.

03Arquitectura y flujo

  1. TarifaExcel del proveedor tal cual llega
  3. NormalizaciónCabeceras, formatos numéricos y referencias
  5. CálculoMargen por SKU con costes configurables
  7. SegmentaciónTramos según umbrales de margen
  9. Excel finalHojas por segmento con colores

04Funcionalidades clave

Parametrizable

Umbrales, columnas y costes se pasan como argumentos: el mismo script sirve para distintos proveedores.

Coloreado por margen

Cada fila se colorea según su tramo para una lectura inmediata.

Una hoja por segmento

Hojas separadas por tramo de margen para trabajar cada grupo por separado.

Priorización

Dentro de cada tramo, ordenado por margen para destacar los SKUs más rentables.

06Retos técnicos

  1. Números con formato europeo

    Comas decimales, símbolos de moneda y celdas de texto se normalizan antes de calcular para no descartar filas en silencio.

  2. Ficheros heterogéneos

    Detección de la fila de cabecera y mapeo de nombres de columna por proveedor.

07Resultados

  • Decisiones de pricing con un criterio único y repetible.
  • Priorización automática de los SKUs de mayor margen.
  • Revisión de una tarifa completa en minutos en lugar de horas.

08Código

segmentar_tarifa.py (simplificado)
import argparse

import pandas as pd

COLORS = {"alto": "#C6EFCE", "medio": "#FFEB9C", "bajo": "#FFC7CE"}


def segment(df: pd.DataFrame, low: float, high: float) -> pd.DataFrame:
    df["margen_pct"] = (df["pvp_sin_iva"] - df["coste"]) / df["pvp_sin_iva"] * 100
    df["segmento"] = pd.cut(
        df["margen_pct"],
        bins=[-float("inf"), low, high, float("inf")],
        labels=["bajo", "medio", "alto"],
    )
    return df.sort_values(["segmento", "margen_pct"], ascending=[False, False])


def main() -> None:
    ap = argparse.ArgumentParser(description="Segmenta una tarifa de proveedor por margen")
    ap.add_argument("tarifa")
    ap.add_argument("--bajo", type=float, default=15, help="margen %% por debajo del cual es bajo")
    ap.add_argument("--alto", type=float, default=30, help="margen %% a partir del cual es alto")
    ap.add_argument("-o", "--out", default="tarifa_segmentada.xlsx")
    args = ap.parse_args()

    df = segment(pd.read_excel(args.tarifa), args.bajo, args.alto)
    paint = lambda row: [f"background-color: {COLORS[row.segmento]}"] * len(row)

    with pd.ExcelWriter(args.out, engine="openpyxl") as xw:
        df.style.apply(paint, axis=1).to_excel(xw, sheet_name="todo", index=False)
        for seg, part in df.groupby("segmento", observed=True):
            part.style.apply(paint, axis=1).to_excel(xw, sheet_name=str(seg), index=False)


if __name__ == "__main__":
    main()

Proyecto interno: el código fuente es privado. Este fragmento está simplificado, sin credenciales ni datos de negocio.
